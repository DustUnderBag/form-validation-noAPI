Form
- On submit
    1. Validate each input field,
    2. Auto-focus the first invalid input field

Every input
- Validate only after user leaves the field,
- Validate during input, display guide message below.

General Validation method
- Determine valid or invalid
- Text color: green for valid, red for invalid.
- Symbol: Tick for valid, exclaimation for invalid.

Email
- length > 0,
- match email pattern.

Country
- Read the value, determine the required postal code format to follow.

Postal Code
- Length > 0,
- Acquire the according postal code format, 
- The code must match the format / regular expression.
    
Password
- length >= 8, Password should contain at least 8 characters.
- Must contain at least 1 lowercase letter, 1 uppercase letter, 1 digit.

Confirm Password
- Must equal to password value.

Validator Methods - for use during validation:
- Input Length, paramter: minlength of input.
- Pattern tester, parameter: regex to test
- Password Confirmation, valid only when it matches password field.
